# 📋 會議紀錄系統（花蓮縣宜昌國小）

單一 HTML 檔案的會議紀錄工具，格式仿照學校「年級學年領域會議／教學研究會」紀錄表（附件三），不需部署、不需伺服器、不需安裝，**直接雙擊 `index.html` 就能在瀏覽器離線使用**。

## 功能

- **會議紀錄本文**：比照紙本表格的欄位（時間、地點、主席／紀錄、出席、討論事項、臨時動議、散會、承辦人／教務主任／校長），空白處都可以直接打字輸入；「討論事項」可以按「＋ 新增討論事項」無限新增。
- **會議實況照片**：可上傳多張照片，每張照片下方有「文字說明」欄位可輸入說明文字；照片會自動壓縮以節省儲存空間，也可以按「＋ 新增照片」增加照片欄位。
- **手寫簽名（可多人）**：簽名區提供簽名畫板，用滑鼠或觸控（手機／平板／觸控筆）直接簽名；簽完一位後按「儲存簽名，新增下一位」即可存檔並清空畫板讓下一位簽，簽錯了可按「清除重簽」重來；已儲存的簽名會列成卡片，可個別刪除或修改姓名／職稱。
- **附件（簽名區後方）**：可上傳任何檔案作為附件，每個附件可個別選擇 PDF 中的顯示方式：「僅顯示檔名」，或「完整顯示附件內容」（圖片、PDF、**Word（.docx）**、**Excel（.xlsx）**、**PowerPoint（.pptx）**、純文字檔可完整內嵌內容；PowerPoint 完整顯示是擷取每張投影片的文字與圖片內容，不會呈現原始版面設計；舊版 `.doc`／`.xls`／`.ppt` 等格式因技術限制僅能顯示檔名，會提示另存新格式後再上傳）。
- **儲存**：按「💾 儲存」會把目前所有內容（文字、照片、簽名、附件）存到瀏覽器的 localStorage，下次打開同一個瀏覽器會自動載入上次的資料；輸入時也會自動每隔一段時間背景儲存一次。
- **匯出 PDF**：按「📄 匯出 PDF」會把整份會議紀錄（打字輸入的內容、上傳的照片、手寫簽名、附件）轉成一份 PDF 檔並下載。頁面設定：
  - 「會議紀錄本文」「會議實況」「簽名區」「附件」四個部分各自從新的一頁開始（不會讓標題跟內容被拆成兩頁）；同一部分內若內容太長需要分頁，也會盡量避開在照片、簽名、附件內容中間換頁。
  - 每一頁上下左右都留 1.5 公分邊界，並在頁面正中央自動加上校徽浮水印。
  - 檔名會自動帶入標題列的「○年級○學年○月份」（例如「六年級115學年9月份會議紀錄.pdf」）。
- **備份／還原**：因為資料只存在單一瀏覽器裡，建議定期按「備份／還原」匯出一份 `.json` 備份檔另外保存，需要時可以用同一個按鈕選擇備份檔還原（例如換電腦、換瀏覽器，或不小心清除瀏覽器資料時）。

## 如何使用

1. 下載 `index.html`（這一個檔案就是完整的系統，不需要其他檔案）。
2. 直接用瀏覽器打開它（雙擊，或拖進瀏覽器視窗）即可使用，全程不需要網路連線。
3. 填寫完成後記得按「儲存」，最後按「匯出 PDF」下載成品。

## 資料儲存與限制

- 所有資料只存在**目前這個瀏覽器**的 localStorage 裡，換瀏覽器、換電腦，或清除瀏覽器資料都會遺失，請務必養成定期「匯出 PDF」或「備份／還原→匯出備份」的習慣。
- 瀏覽器的 localStorage 通常有幾 MB 的容量限制，照片上傳時系統會自動壓縮（最長邊約 1400px、JPEG 品質 0.75）以節省空間，但仍建議不要一次塞入過多、過大的照片或附件；若「儲存」時出現失敗訊息，代表資料量太大，可以先匯出 PDF／備份，並刪除一些照片或附件後再繼續。
- 附件單檔上限 15MB；選擇「僅顯示檔名」的附件不會把檔案內容存進瀏覽器，換瀏覽器或清除資料後若想改成「完整顯示附件內容」，需要重新選擇該檔案一次。
- 簽名、照片、附件皆為單機操作，不會上傳到任何伺服器。
