# 📋 會議紀錄系統（花蓮縣宜昌國小）

單一 HTML 檔案的會議紀錄工具，格式仿照學校「年級學年領域會議／教學研究會」紀錄表（附件三），不需部署、不需伺服器、不需安裝，**直接雙擊 `index.html` 就能在瀏覽器離線使用**。

## 功能

- **多份會議紀錄（本機資料庫，依年級分資料夾）**：不再只能存一份紀錄。開啟系統會先看到「選擇要開啟的會議紀錄」畫面，是一層「資料夾」畫面——一～六年級六個資料夾（依紀錄實際填寫的年級分類；沒填年級的歸到「未分類」），每個資料夾顯示裡面有幾份紀錄，**點進資料夾才會看到裡面的紀錄清單**，不會因為紀錄一多就在畫面上無限往下延伸。
  - 「＋ 新增一份會議紀錄」「匯入備份檔」「匯出全部紀錄備份」這三個按鈕在資料夾列表、或已經點進某個資料夾時都看得到，不需要特別切換畫面。
  - 資料夾內：「開啟」進入編輯；「匯出備份」單獨匯出某一份紀錄；「刪除」移除某一份紀錄（不影響其他份）；點選標題文字可重新命名（未命名的話系統會依標題列的年級／學年／月份自動命名，只改名稱不影響分類）。
  - 每份紀錄旁邊都有「📁 資料夾：」下拉選單，可以直接把這份紀錄改分到任何一個年級或「未分類」——不需要打開紀錄本身、不需要填年級欄位也能分類，例如跨年級的聯合會議，或年級欄位一時沒填的紀錄，都能用這個手動指定要放進哪個資料夾；手動指定過的紀錄之後就固定留在那個資料夾，不會再被系統自動改分類。
  - 編輯畫面右上角「🗂 切換紀錄」會先自動存檔，然後直接跳回「目前這份紀錄所在的資料夾」（例如正在編輯六年級的紀錄，按下去就直接看到六年級資料夾裡的清單），資料夾列表畫面也有「← 返回資料夾列表」可以再切去別的年級。
  - 一般情況下重新整理瀏覽器會直接回到「上次開啟的那一份」繼續編輯，不需要每次都重新選擇。
- **會議紀錄本文**：比照紙本表格的欄位（時間、地點、主席／紀錄、出席、討論事項、臨時動議、散會、承辦人／教務主任／校長），空白處都可以直接打字輸入；「討論事項」可以按「＋ 新增討論事項」無限新增。
- **會議實況照片**：可上傳多張照片，每張照片下方有「文字說明」欄位可輸入說明文字；照片會自動壓縮以節省儲存空間，也可以按「＋ 新增照片」增加照片欄位。
- **手寫簽名（可多人）**：簽名區提供簽名畫板，用滑鼠或觸控（手機／平板／觸控筆）直接簽名；簽完一位後按「儲存簽名，新增下一位」即可存檔並清空畫板讓下一位簽，簽錯了可按「清除重簽」重來；已儲存的簽名會列成卡片，可個別刪除或修改姓名／職稱。
- **附件（簽名區後方）**：可上傳任何檔案作為附件，每個附件可個別選擇 PDF 中的顯示方式：「僅顯示檔名」，或「完整顯示附件內容」（圖片、PDF、**Word（.docx）**、**Excel（.xlsx）**、**PowerPoint（.pptx）**、純文字檔可完整內嵌內容；PowerPoint 完整顯示會排成像「講義（6 張投影片／頁）」的兩欄小卡格式，方便一次看到較多張投影片，但只擷取文字與圖片內容，不會呈現原始版面設計與色彩；舊版 `.doc`／`.xls`／`.ppt` 等格式因技術限制僅能顯示檔名，會提示另存新格式後再上傳）。
- **儲存**：按「💾 儲存」會把目前所有內容（文字、照片、簽名、附件）存到瀏覽器的 localStorage，下次打開同一個瀏覽器會自動載入上次的資料；輸入時也會自動每隔一段時間背景儲存一次。
- **匯出 PDF**：按「📄 匯出 PDF」會把整份會議紀錄（打字輸入的內容、上傳的照片、手寫簽名、附件）轉成一份 PDF 檔並下載。頁面設定：
  - 「會議紀錄本文」「會議實況」「簽名區」「附件」會依序排下來，內容短的話會盡量排在同一頁（不會浪費空白頁）；但每個部分的標題絕對不會跟它下面的內容被拆成兩頁——如果標題下面接不了完整的第一張照片／簽名／附件，就會整段一起換到下一頁。同理，每個附件的檔名也不會跟它自己的內容被拆開。
  - 每一頁上下左右都留 1.5 公分邊界，並在頁面正中央自動加上校徽浮水印。
  - 檔名會自動帶入標題列的「○年級○學年○月份」（例如「六年級115學年9月份會議紀錄.pdf」）。
- **備份／還原**：編輯畫面的「備份／還原」是針對「目前這份」紀錄——匯出這一份的備份，或用備份檔覆蓋這一份。若要備份／還原「全部紀錄」，請到「切換紀錄」畫面使用「匯出全部紀錄備份」「匯入備份檔」。因為資料只存在單一瀏覽器裡，建議定期做一次全部紀錄的備份另外保存（例如換電腦、換瀏覽器，或不小心清除瀏覽器資料時可以用來復原）。

## 如何使用

1. 下載 `index.html`（這一個檔案就是完整的系統，不需要其他檔案）。
2. 直接用瀏覽器打開它（雙擊，或拖進瀏覽器視窗）即可使用，全程不需要網路連線。
3. 填寫完成後記得按「儲存」，最後按「匯出 PDF」下載成品。

## 資料儲存與限制

- 所有紀錄都只存在**目前這個瀏覽器**的 localStorage 裡，換瀏覽器、換電腦，或清除瀏覽器資料都會遺失，請務必養成定期「匯出 PDF」或到「切換紀錄」畫面「匯出全部紀錄備份」的習慣。
- 瀏覽器的 localStorage 通常只有幾 MB 的容量限制，是**所有紀錄共用**的（不是一份紀錄一份額度），紀錄數量越多、照片附件越多，越容易碰到上限；照片上傳時系統會自動壓縮（最長邊約 1400px、JPEG 品質 0.75）以節省空間，但仍建議不要累積過多份含大量照片／附件的紀錄；若「儲存」或「匯入備份檔」時出現「瀏覽器儲存空間已滿」的失敗訊息，代表資料量太大（例如：匯出全部紀錄備份後，馬上又把同一份備份檔匯入回去，會變成新增一份份量幾乎一樣的資料，等於用量瞬間變兩倍，很容易超過容量上限），可以先匯出 PDF／備份，並刪除一些照片、附件或不需要的舊紀錄後再繼續；匯入備份檔時若中途容量不足，已經成功匯入的紀錄不會遺失，訊息會告知目前為止實際匯入了幾份。
- 若曾經使用過舊版（單一紀錄）的這個系統，第一次打開新版時會自動把舊資料轉成一份新格式的紀錄，不需要手動處理。
- 附件單檔上限 15MB；選擇「僅顯示檔名」的附件不會把檔案內容存進瀏覽器，換瀏覽器或清除資料後若想改成「完整顯示附件內容」，需要重新選擇該檔案一次。
- 簽名、照片、附件皆為單機操作，不會上傳到任何伺服器。
