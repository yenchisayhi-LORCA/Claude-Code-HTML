損益資料表：簡損表（逐月＋年度累計）與各門市明細兩種版型，格線像 Excel，數字靠右、科目靠左。

## 版型
- **共通**：外層面板 `card`、`line` 邊框、`radius-md`；標題用 `card-title`，下方 2px `charcoal` 線，單位註記放標題旁；表頭 `charcoal` 底、白字、置中；儲存格全格線（`line-soft`）；偶數列 `paper` 斑馬紋。
- **簡損表**：面板內分年度，新年度在上；年度累計欄用 `paper-dim` 底並加粗；營業收入、營業淨利為合計列（加粗、上緣 2px 雙線 `charcoal`）。
- **門市明細**：第一欄為排名、第二欄為門市名稱；營業利益欄加 `brand-tint` 資料條（長度＝該列值／最大值）；最後一欄放分級標籤（優／中／劣）；最底一列為合計。

## 規則
- 單位「新台幣千元」或「百萬元」寫在標題旁，四捨五入到整數（百萬元表保留兩位小數），千分位逗號。
- 虧損以 `neg` 粗體顯示（在 `paper-dim` 底的合計列與累計欄上改用 `neg-ink`，對比才達 4.5:1）；增減率帶正負號與一位小數，營收類增加＝`pos-ink`、減少＝`neg`（成本類相反）。
- 無法計算（基期為 0 或負）顯示 `N/A`，不要硬算百分比。
- 分級門檻寫在表格下方的 `caption`（例如「食材成本率 < 37% 為優」）。
- 欄位多時外層橫向捲動，第一欄保持不換行。
