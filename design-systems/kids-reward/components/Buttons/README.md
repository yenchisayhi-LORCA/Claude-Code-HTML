# Buttons

藥丸形按鈕（`radius-pill`），Noto Sans TC 900、17px，內距 16×30；hover 上浮 2px，不用陰影。

| class | 底 | 字 | 用途 |
| --- | --- | --- | --- |
| `btn-primary` | `tomato-deep` | `white` | 主要動作（儲存） |
| `btn-secondary` | `block-blue` | `white` | 次要實心動作（＋新增小孩） |
| `btn-accent` | `sun-yellow` | `ink-navy` | 兌換、領取 |
| `btn-danger` | `tomato-deep` | `white` | 退回 |
| `btn-ghost` | 透明 + 3px `ink-navy` 框 | `ink-navy` | 取消、上個月 |
| `:disabled` | `surface-disabled` | `text-disabled` | 停用 |

- `btn-icon-only`：34×34、`cream-paper` 底、`radius-icon-btn`，放 18px 線稿圖示（編輯、刪除）。
- `btn-add-kid`：48px 圓、3px `border-dashed`（#8F8CB5，3.1:1）虛線框，hover 變 `tomato-red`。
- 紅色按鈕底用 `tomato-deep`，白字 4.57:1。
