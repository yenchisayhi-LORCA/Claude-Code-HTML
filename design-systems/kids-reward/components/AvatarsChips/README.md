# AvatarsChips

- **色塊小怪獸**：viewBox 60 的 blob（固定 path）+ 兩個 r=3 圓點 + 微笑弧線（stroke 3）。顏色由小孩 id hash 選自 `bubble-pink`、`lake-teal`、`sun-yellow`、`block-blue`；藍色那隻五官用白色。
- **kid-tab**：藥丸形，44px 頭像 + 名字（900）+ Gluten 14px 餘額。選中：`sun-yellow` 底、`ink-navy` 字；未選中：透明底、`text-body` 名字、`text-muted` 餘額。
- **icon-chip**：64px 淺色 blob，四色輪替，圓角 40–65%、旋轉 ±4 度（皆由 id hash 決定），內放 36px 線稿圖示。
