# CASHBOX 損益儀表板

給連鎖 KTV 營運與財務團隊用的損益分析介面風格：像一張排版整齊的 Excel 報表——白底卡片、深灰表頭、細格線、高密度的數字，並以藍、綠、橘、紅四種企業色把「發生了什麼事」講清楚。版面結構與 CB、HD 儀表板同一套，只是換成 CASHBOX 專屬的企業色與報表風視覺。

## 內容原則（Content fundamentals）

- **語言**：一律使用台灣繁體中文與台灣慣用詞（軟體、影片、資料）。數字用阿拉伯數字加千分位，單位寫在說明裡：「單位：新台幣千元」。
- **語氣**：像資深分析師寫給主管的短評——先講結論，再講數字，最後講原因。不用驚嘆號、不用表情符號當裝飾（燈號圓點例外）。
- **句型**：「本期為 X 元，較上期的 Y 元增加／減少 Z 元（±N%）」。本期數字開頭，再說明增減；百分比永遠帶正負號與一位小數。
- **名稱**：門市用顯示名稱，不用分類帳內部代號。
- **科目稱呼**：用「科目小類」（人力成本、銷貨成本、水電瓦斯、辦公成本、租金成本、版權費用、折舊攤提、廣告費行銷、管顧費用、稅捐、其他）。
- **指標定義**：營業淨利＝營業收入－全部成本費用；EBITDA＝營業淨利＋折舊攤提。

範例：
> 門市小計營業淨利下滑　−12.3%
> 2026年6月營業淨利為 4,820,000 元，較2026年5月的 5,497,000 元減少 677,000 元（−12.3%），建議搭配各門市與科目觀察確認具體成因。

## 視覺基礎（Visual foundations）

- **底色層次**：`paper`（頁面，中性淺灰）→ `card`（卡片與頁首，純白，更亮）→ `paper-dim`（次層：合計列、說明區、未啟用頁籤）。層次靠色差與 `line` 細邊框，陰影極輕。
- **字型**：全部使用 Noto Sans TC（無襯線），不用襯線字；數字一律等寬數字（`font-variant-numeric: tabular-nums`）。不載入外部字型，字型堆疊見「交付原則」第 5 點。
- **頁首與品牌簽名**：白底 `card` 放報表標題（不放標誌圖）；頁首底緣是 5px 的四色條，由左到右依序為 `brand` 藍、`pos` 綠、`gold` 橘、`neg` 紅，等寬。這是企業色的簽名，不可省略、不可改順序、不可換色。四色條之下接 `charcoal` 深灰的功能列（TabNav）。
- **顏色語意**（最重要）：
  - `brand` 藍：導覽與主要互動（啟用頁籤、按鈕外框、章節編號）、本期主數列、資料條。
  - `charcoal` 深灰：表頭、功能列、圖表與表格標題下的 2px 線、合計列上緣的雙線。
  - `gold` 橘：提示與注意（觀察、說明邊條）、「中」級。
  - `pos` 綠：改善、成本下降、「優」級；`neg` 紅：虧損、成本上升、「劣」級。
  - **成本類數字的紅綠要反過來想**：成本增加用紅、減少用綠；營收／淨利類則增加用綠、減少用紅。
  - **小字的顏色不用企業原色**：正值文字用 `pos-ink`，留意文字用 `gold-ink`（放在 `gold-soft` 上），重大文字用 `neg-ink`（放在 `neg-soft` 上）。企業色的綠（約 3.5:1）與橘（約 2.5:1）對比不足，只能當色點、邊條、色帶與圖表數列。
  - 虧損（負值）金額一律以 `neg` 粗體顯示。
- **形狀**：報表風方正。按鈕、頁籤、狀態標籤用 `radius-xs`（2px）；卡片與表格容器 `radius-md`（4px）；大面板 `radius-lg`（6px）；`radius-pill` 只留給 8px 燈號圓點與計數徽章。
- **版面**：最大寬度 1440px、左右 20px；區塊之間 14px；章節間距 32px；功能列黏在頁面頂端（sticky）。整體偏高密度，內文 12–13px。
- **表格**：像 Excel——全格線（`line-soft`）、數字靠右、科目靠左、偶數列 `paper` 斑馬紋；表頭 `charcoal` 底白字置中；合計列加粗、`paper-dim` 底，上緣 2px 雙線（`charcoal`）；營業利益欄可加 `brand-tint` 資料條（長度＝該列值／最大值）；虧損數字紅字。
- **圖表**：本期用 `chart-1` 藍實線，去年同期用 `chart-5` 灰虛線；多數列依序取 `chart-1`～`chart-6`；環圈圖相鄰色段留 2px 白縫；圖例一定附數值或百分比。圖表標題用 `card-title`，下方 2px `charcoal` 線。
- **陰影**：只有三種（panel、float、sticky），都是極輕的低透明度陰影。

## 使用規則（Usage rules）

1. 文字色只用 `ink`、`ink-body`、`ink-soft`；在 `charcoal` 深灰底上才用 `card`（白）、`hero-sub`、`hero-muted`。
2. `gold`、`pos` 不當文字色，也不在其上放白字；要表達狀態時用「淡底＋深色文字＋同色 1px 細框」的標籤（優／中／劣、正向／留意／重大），或搭配色點與粗體。
3. KPI 條與結論卡的頂端 3px 色條表示指標類型：藍＝營收與規模、綠＝利潤、橘＝比率、紅＝成本與風險、灰＝佔比與中性。色條代表類型而非好壞。
4. 一頁只有一個啟用頁籤（白字粗體、`gold` 2px 底線）；其餘為 `hero-sub` 字。
5. 數字顯示：千元表四捨五入到整數；需要精度時另存原值（data-raw），不要在畫面上放小數。
6. 頁首不放標誌圖，以四色條與報表標題作為品牌簽名；若使用者自行加入標誌，須放在 `card` 底上、不拉伸、不重新上色。
7. 分級（優／中／劣）一定附文字，不可只靠顏色；成本率分級的門檻由各分析另行定義並寫在表格下方。

## 何時使用這份設計系統

- 用於 CASHBOX／KTV 門市損益、成本、EBITDA 等分析儀表板與報表，沿用上述色彩、字型與元件。
- 匯出 Excel、Word、CASHBOX RAW 時，依「匯出檔案規範」頁的格式（字型、數字格式、合併表頭、頁面設定）。
- 一次性分析用的 HTML 儀表板，須遵守下方「交付原則」。

## 交付原則

一次性分析用的 HTML 儀表板，一律照以下原則交付：

1. **單機、單一 HTML 檔，離線可用**：自己的樣式、腳本、圖示都內嵌在同一個檔案裡，雙擊就能在瀏覽器開啟；函式庫與字型的取得方式見第 3–5 點。不部署到任何雲端或網站，也不 push 到任何遠端儲存庫。
2. **資料只在瀏覽器裡處理**：使用者匯入的分類帳與調整數只在本機記憶體中運算，不上傳到任何伺服器、不留存。不使用 localStorage、sessionStorage、IndexedDB 或資料庫；關閉或重新整理頁面後資料即消失，每次使用重新匯入。
3. **資料絕不外送**：頁面不連任何外部網址。用內容安全政策（CSP）封鎖所有對外連線，放在 `<head>` 最前面：

```html
<meta http-equiv="Content-Security-Policy"
  content="default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; connect-src 'none'; worker-src blob:; form-action 'none'; base-uri 'none'">
```

   其中 `connect-src 'none'` 讓頁面無法用 fetch、XHR 或 sendBeacon 把資料送出去，`script-src` 不開放任何外部網址，這是防止資料外流的關鍵。
4. **函式庫一律內嵌**：xlsx、exceljs、chart.js 的原始碼（固定版本）直接放進同一個 HTML 檔，不從 CDN 載入，因此斷網也能用，也不會執行任何第三方即時下載的程式碼。
5. **字型不載入外部資源**：不使用 Google Fonts。字型依序為 Noto Sans TC（電腦裡有才會用）、PingFang TC、微軟正黑體，最後退回系統預設字型，斷網時版面不會壞。
6. 匯出（Excel、Word）由瀏覽器直接在本機產生並下載，不經過任何伺服器。

## 圖示與資產

- **標誌**：本設計系統不附標誌圖檔，品牌識別只靠企業色與四色條。
- **圖示**：不使用圖示庫。科目圖示是單一中文字（人、貨、電、水、修）放在 36px 方塊（`radius-xs`）裡，底色為 `brand-soft` 或 `gold-soft`；章節編號是 24px 藍色細框方塊（`radius-xs`）。

## 元件

PageHero（標題頁首與四色條）、TabNav（深灰功能列）、Buttons（方正按鈕與標籤）、ConclusionCard（結論字卡／KPI 卡）、DataTable（損益表格）、AnomalyCard（異常觀察卡）。每個元件都有即時預覽與使用說明；預覽中的門市名稱與數字皆為示意資料。
