頁面最上方的白底頁首：左側放報表標題，右側放期間與涵蓋範圍，底緣是一條四色細條。

## 結構
- 底色 `card`，內距 12px 20px。
- 左側：報表標題（`hero-title` 風格，`charcoal` 色）。
- 右側：期間與涵蓋門市數、單位與資料性質，用 `caption`、`ink-soft`，靠右兩行。
- 底緣 5px 四色條：`brand`、`pos`、`gold`、`neg` 依序等寬，是品牌簽名，不可省略、不可改順序或換色。

## 規則
- 一頁只放一個頁首；其下直接接 TabNav 功能列。
- 頁首不放標誌圖。
- 視窗窄時標題縮為 18px，右側資訊移到標題下方。
- 頁首右側可放「匯出報表」外框按鈕。
