門市異常觀察卡：左側放門市與狀態，右側放期間變動標題、說明與逐科目證據。

## 結構
- 兩欄格線（200px｜彈性），中間以 1px `line` 虛線分隔；視窗窄於 720px 時改為單欄、虛線移到下方。
- 左欄：狀態標籤（正向／留意／重大／轉虧為盈）→ 門市名稱（17px 粗體）→ 指標（變動金額與百分比）。
- 右欄：`期間 A 金額 → 期間 B 金額` 標題、一句說明、證據區（`paper-dim` 底、左 3px `gold` 邊線）。
- 證據列：以小標籤（收入、人力成本、銷貨成本、水電瓦斯、辦公成本）開頭，各列用虛線分隔，每項格式為「科目：前期 → 本期（±差額）」。

## 規則
- 依 EBITDA 變動金額由小到大排序，少賺錢的門市排最前。
- 標籤判定：轉盈為虧／虧損擴大／獲利衰退 ≥50% 為「重大」（`neg-soft`／`neg-ink`）；轉虧為盈與改善為「正向」（`pos-soft`／`pos-ink`）；其餘「留意」（`gold-soft`／`gold-ink`）。
- 每個科目小類最多列前三項貢獻最大的變動；沒有變動時寫明「無明顯…變動」。
