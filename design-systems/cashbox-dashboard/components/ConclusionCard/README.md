結論字卡／KPI 卡：用一張卡片講一個結論，由分類標籤、大數字、短標題、一段說明組成。

## 結構
- 容器：`card` 底、`line` 邊框、`radius-md`、內距 12px 14px；頂端 3px 色條表示類型。
- 色條：`brand`＝營收與規模、`pos`＝利潤與正向、`gold`＝比率與提示、`neg`＝成本與風險、`charcoal`＝佔比與中性。
- 分類標籤：`eyebrow`、`ink-soft`。
- 大數字：`kpi-number`（20px 粗體、等寬數字），內容是金額、百分比或門市名稱。
- 標題：`card-title`；說明：`body-card`，顏色 `ink-body`。增減率小字用 `pos-ink`／`neg`。

## 規則
- 一張卡片只講一件事；說明不超過三行。
- KPI 條橫排時等寬、卡片之間 0 間距共用 1px 邊線；結論字卡用自動格線（`minmax(240px,1fr)`），卡片之間 14px。
- 色條代表類型而非好壞；好壞用數字旁的文字與顏色表達。
