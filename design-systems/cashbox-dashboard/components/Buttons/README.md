方正按鈕、狀態標籤與燈號圓點。按鈕與標籤用 `radius-xs`（2px），文字 12px 粗體；只有燈號圓點是圓的。

## 變體
- **外框按鈕（主要）**：`brand` 外框與文字、透明底；hover 填 `brand-soft`。用於展開／收合、查看明細、產生分析、匯出。展開狀態箭頭旋轉 180°。
- **幽靈按鈕**：`line` 外框、`ink-soft` 文字；hover 時轉 `brand`。用於重設、次要動作。
- **上傳按鈕**：沿用外框按鈕樣式（`brand` 外框與文字、`card` 底）。
- **狀態標籤**：淡底＋深色文字＋同色 1px 細框。正向／「優」（`pos-soft`／`pos-ink`／`pos`）、留意／「中」（`gold-soft`／`gold-ink`／`gold`）、重大／「劣」（`neg-soft`／`neg-ink`／`neg`）；一律短詞（1–4 字）。
- **燈號圓點**：8px，綠＝改善或持平、橘＝下滑但仍為正、紅＝由正轉負或虧損擴大；必須附文字圖例。

## 規則
- 不使用實心橘或實心綠加白字（對比約 2.5:1、3.5:1）；要實心時只用 `brand`、`charcoal`、`neg`。
- 一個區塊內最多一組主要外框按鈕，避免並排超過三個。
- 不可只靠顏色表達狀態，標籤要有文字。
