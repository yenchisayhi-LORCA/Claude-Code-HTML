頁面主導覽：頁首下方一條深灰功能列，黏在視窗頂端（`position:sticky; top:0`）。

## 規則
- 容器：`charcoal` 底、`shadow-sticky`，內距 7px 20px，項目間距 24px。
- 啟用項目：`card`（白）字、粗體、下方 2px `gold` 底線；未啟用：`hero-sub` 字；hover 時文字變白、底線用 `hero-muted`。
- 同一時間只有一個啟用項目；文字簡短（2–8 字），不使用圖示。
- 切換項目只顯示／隱藏面板，資料更新由各面板自行處理。
- 頁面底部可另放「工作表」式頁籤（`paper-dim` 底、啟用者白底加 2px `brand` 上線）作為次要切換，一頁最多一組。
