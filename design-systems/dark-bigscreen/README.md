# 大螢幕看板

給會議室投影、門市牆面螢幕使用的營運看板風格：深海軍藍底、超大 KPI 數字、薄荷綠／天藍／紫／琥珀四種發光強調色，在 3–5 公尺外也能一眼看出重點。整個看板固定為 1920×1080 一屏，不捲動、不互動，一屏只講一件事。

## 內容原則（Content fundamentals）

- **語言**：一律使用台灣繁體中文與台灣慣用詞（軟體、影片、資料）。數字用阿拉伯數字，大數字省略千分位以外的裝飾，單位放在數字旁的小字。
- **語氣**：看板不寫句子，只寫「名詞＋數字」。標題 2–8 字（「本月營收」「食材成本率」），不加冒號、驚嘆號與表情符號。
- **數字**：KPI 以「萬」「百萬（M）」「%」為單位，四捨五入到一位小數；增減一律帶 ▲／▼ 與一位小數百分比，後接「較去年同期」「較上月」等比較基準。
- **一屏一事**：每一屏只回答一個問題（今天賣得怎麼樣？哪幾間店最好？），不放說明文字與註腳；細節留給桌面版儀表板。
- **名稱**：門市用顯示名稱，不用內部代號。

範例：
> 本月營收　48.6 M　▲ 6.2%　較去年同期

## 視覺基礎（Visual foundations）

- **畫布**：1920×1080（16:9），`overflow:hidden`，左右邊距 40px、上下 26px，區塊間距 20px。視窗大小不同時，用 `transform: scale()` 整張縮放並置中，不改版型。
- **底色層次**：`paper`（頁面）→ `card`（面板）→ `card-raised`（KPI 卡上緣）。頁面背景在頂端有一圈 `paper-glow` 放射亮光；層次靠 `line` 1px 外框與色差，不用陰影（唯一例外是 `shadow-glow`，只給「即時」燈號）。
- **字型**：Noto Sans TC 無襯線；標題與主數字 800 粗；所有數字用等寬數字（`tabular-nums`）。最小字級 17px（座標軸），表格 25px、圖例 23px、面板標題 28px、KPI 標籤 26px、KPI 主數字 92px。
- **版面**：由上而下三列——頁首（標題＋日期）→ 一排 4 張 KPI 卡（等寬）→ 中段 3 欄面板（趨勢圖 1.55fr、占比 1fr、排行或表格 1fr）。中段撐滿剩餘高度，面板內部自行縮放，不出現捲軸。
- **顏色語意**：
  - KPI 卡數字依序為 `chart-1` 薄荷、`chart-2` 天藍、`chart-3` 紫、`chart-4` 琥珀；顏色代表「第幾個指標」，不代表好壞。
  - 好壞只用 `pos`（薄荷）、`gold`（琥珀）、`neg`（玫瑰紅）三色，一律搭配 ▲▼ 或文字標籤。
  - 去年同期／對照數列用 `chart-ly`，一律虛線。
- **形狀**：面板與 KPI 卡圓角 18px；資料條、標籤、燈號是膠囊形（`radius-pill`）；圖例色塊 2px 方角。
- **圖表**：本期線 3px 薄荷實線加 12% 面積填色；資料點為卡片色填滿＋薄荷 2px 外圈；格線只畫橫線（`line`）；環圈圖清單每列 23px 並附百分比；排行長條由 `accent-deep` 往 `accent` 漸層、軌道 `line`。
- **表格**：25px、置中、只有橫向列線（`line`）；第一欄（列名）靠左、`ink-soft`；分級標籤是膠囊（淡底＋同色字）。

## 使用規則（Usage rules）

1. 文字色只用 `ink`、`ink-soft`，以及 `pos`／`gold`／`neg`／`chart-*` 這些高對比強調色（在 `card` 上皆 ≥ 6.6:1）；`chart-ly` 與 `line` 只做圖形。
2. 每一屏最多 4 張 KPI 卡，最多 3 個面板；超過就拆成輪播的下一屏，而不是縮小字。
3. 不使用小於 17px 的字；不使用細於 400 的字重。
4. 狀態（優／中／劣、▲▼）一定附文字或符號，不可只靠顏色。
5. 發光效果只用在「即時」燈號，不套在 KPI 數字、面板或圖表上。
6. 看板是唯讀的：不放下拉選單、輸入框與按鈕；範圍、日期切換在桌面版儀表板完成。若需要輪播，每屏停留 15–30 秒並顯示屏幕頁碼點。
7. 資料更新時間一律放在右上角（`screen-meta`），避免有人看到過期數字。

## 何時使用這份設計系統

- 會議室、辦公室牆面、門市後場的營運看板（營收、客數、成本率、排行榜），觀看距離 3 公尺以上。
- 要放進簡報投影或電視牆的畫面。
- 需要細節與互動時，改用桌面版儀表板風格（例如 CASHBOX 報表風），不要在這份風格上硬塞資料。

## 交付原則

一次性分析用的 HTML 儀表板，一律照以下原則交付：

1. **單機、單一 HTML 檔，離線可用**：自己的樣式、腳本、圖示都內嵌在同一個檔案裡，雙擊就能在瀏覽器開啟；函式庫與字型的取得方式見第 3–5 點。不部署到任何雲端或網站，也不 push 到任何遠端儲存庫。
2. **資料只在瀏覽器裡處理**：使用者匯入的分類帳與調整數只在本機記憶體中運算，不上傳到任何伺服器、不留存。不使用 localStorage、sessionStorage、IndexedDB 或資料庫；關閉或重新整理頁面後資料即消失，每次使用重新匯入。
3. **資料絕不外送**：頁面不連任何外部網址。用內容安全政策（CSP）封鎖所有對外連線，放在 `<head>` 最前面：

```html
<meta http-equiv="Content-Security-Policy"
  content="default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; connect-src 'none'; worker-src blob:; form-action 'none'; base-uri 'none'">
```

   其中 `connect-src 'none'` 讓頁面無法用 fetch、XHR 或 sendBeacon 把資料送出去，`script-src` 不開放任何外部網址，這是防止資料外流的關鍵。
4. **函式庫一律內嵌**：xlsx、exceljs、chart.js 的原始碼（固定版本）直接放進同一個 HTML 檔，不從 CDN 載入，因此斷網也能用，也不會執行任何第三方即時下載的程式碼。
5. **字型不載入外部資源**：不使用 Google Fonts。字型依序為 Noto Sans TC（電腦裡有才會用）、PingFang TC、微軟正黑體，最後退回系統預設字型，斷網時版面不會壞。
6. 匯出（Excel、Word）由瀏覽器直接在本機產生並下載，不經過任何伺服器。

## 圖示與資產

- 不附標誌圖檔，也不使用圖示庫。品牌識別靠深海軍藍底與薄荷綠主色；若需標誌，放在頁首標題左側、高度 44px，並使用淺色版本。
- 燈號是 14px 圓點，發光用 `shadow-glow`。

## 元件

PageHero（大標題與即時燈號）、KpiCard（超大 KPI 卡）、RankBars（排行長條）、DataTable（大螢幕表格）。每個元件都有即時預覽與使用說明；預覽為了放進卡片已縮小 50%，實際尺寸見各元件說明；示意資料皆為虛構。
