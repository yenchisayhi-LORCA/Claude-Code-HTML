排行長條：由高到低列出各門市（或品項）的數值，一列一條，適合放在中段最右欄。

## 結構
- 每列：名稱 110px（`bar-label`、`ink`）→ 長條（高 12px、`radius-pill`、軌道 `line`）→ 數值 84px（`bar-label`、600、`ink`、靠右）。
- 長條填色由 `accent-deep` 往 `accent` 的水平漸層；長度＝該列值／最大值。
- 列距約 1–9px，依面板高度自動分配，面板內不出現捲軸。

## 規則
- 最多 8 列；超過只留前 8 並在 meta 註明。
- 由高到低排序；末位若為負向（低於目標）可把長條改用 `neg`，並附文字或 ▼。
- 數值一律顯示，不只靠長條長度。
