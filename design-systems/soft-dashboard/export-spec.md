# 匯出檔案規範

儀表板匯出 Excel、Word 時，要盡量還原畫面上的樣子，並遵守以下規格。

## 共通規則

- **即時匯出**：每次匯出都以當下畫面上的資料與條件重新產生，不用快取、不保留舊資料。
- **一律保留標題**：檔案最上方放儀表板標題、副標說明、分析期間與涵蓋範圍；每張表上方放表標題與單位；圖表連同標題與註記一起匯出。
- 畫面上不可見的按鈕、輸入框、下拉選單都不匯出；無法計算的百分比輸出 `N/A`，不要輸出 0。
- 匯出由瀏覽器在本機產生並下載，不經過任何伺服器。

## Excel（.xlsx）

- **字型**：微軟正黑體；標題 14pt 粗體，表頭 10.5pt 粗體，內文 10pt。
- **表頭**：`paper-dim`（#EFE6D8）底、`ink-soft`（#6F6051）粗體字（對比約 4.9:1）；僅下框線 1px #EADFCE。
- **標題色**：`ink`（#4A3F35）粗體；重點／次標題用 `accent-ink`（#A8412A）；次要說明 `ink-soft`。
- **數字顏色**：正向 `pos-ink`（#46742E）、負向 `neg-ink`（#A33638）；數字格式 `#,##0_);[Red](#,##0)` 時以條件格式覆蓋為 `neg-ink`。
- **數字格式**：金額 `#,##0_);(#,##0)`；百分比 `0.0%;(0.0%)`（儲存為小數）。
- **對齊**：第一欄靠左，其餘靠右；列線只畫橫向 1px #EADFCE；無斑馬紋、無垂直線。
- **工作表底色**：整張白底（不填 `paper`），避免列印耗墨。
- **頁面設定**：直向、縮放至一頁寬、窄邊界。
- **檔名**：`營運回顧_YYYYMMDD.xlsx`。

## Word（.doc）

- 內容順序與畫面一致；顏色、字型直接寫入行內樣式；所有明細表展開。
- 標題 20pt，章節標題 14.5pt 並帶 4px `accent`（#E07A5F）左邊線；表格僅橫向 1px 淺線。
- 檔名：`營運回顧_YYYYMMDD.doc`。
