膠囊形頁籤：一條 `paper-dim` 軌道裡放數個頁籤，啟用的那個浮起成實心 `accent-ink`。

## 結構
- 軌道：`paper-dim` 底、`radius-pill`、內距 3px；頁籤之間不加間距。
- 頁籤：13px、700、`ink-soft` 文字，內距 5px 16px、`radius-pill`；hover 時文字變 `ink`。
- 啟用：`accent-ink` 底、`card` 白字（約 5.4:1）。
- 停用：文字 `ink-soft`、透明度 .5、不可點擊。

## 規則
- 一組頁籤只有一個啟用項目；文字 2–6 字，不使用圖示。
- 一個頁面最多一組主要頁籤；篩選用的短選項（月／季）可用同樣外觀的小型版本（12px）。
- 切換頁籤只顯示／隱藏面板。
