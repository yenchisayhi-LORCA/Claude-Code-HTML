# 柔和

給日常營運回顧、店長週報、主管簡報用的溫和儀表板風格：暖米色底、奶油白大圓角卡片、陶土橘主色，沒有邊框與硬線條，像一本排得舒服的手帳。適合需要「讀得下去」而不是「盯著看」的場合。

## 內容原則（Content fundamentals）

- **語言**：一律使用台灣繁體中文與台灣慣用詞（軟體、影片、資料）。數字用阿拉伯數字加千分位，單位寫在標題或 caption 裡。
- **語氣**：親切但不口語——像店務助理寫給店長的週報。先講結論，再講數字；不用驚嘆號與表情符號。
- **句型**：「本月營收 48.6 百萬元，較去年同期成長 6.2%」。增減帶 ▲／▼ 與一位小數百分比，後接比較基準。
- **標題**：卡片標題 4–12 字（「月營收趨勢」「各品項占比」），不寫成句子。
- **名稱**：門市用顯示名稱，不用內部代號。

範例：
> 本月營收　NT$ 48.6M　▲ 6.2%　較去年同期

## 視覺基礎（Visual foundations）

- **底色層次**：`paper`（頁面，暖米色）→ `card`（卡片，奶油白）→ `paper-dim`（表頭列、軌道、未啟用區塊）。**卡片不加邊框**，靠 `shadow-panel` 柔和陰影與色差浮起。
- **字型**：Noto Sans TC 無襯線；標題 700、卡片標題 600、內文 400；數字用等寬數字（`tabular-nums`）。不載入外部字型，字型堆疊見「交付原則」第 5 點。
- **形狀**：圓潤。卡片 `radius-lg`（20px）；按鈕與輸入框 `radius-md`（12px）；徽章、標籤、頁籤、資料條與軌道是膠囊（`radius-pill`）；圖例色塊 `radius-xs`（3px）。
- **版面**：最大寬度 1280px、左右 28px；KPI 排 4 欄、卡片間距 16px；中段 1.6fr＋1fr 兩欄（趨勢圖＋占比），下方 1fr＋1fr（排行＋表格）。卡片內距 20px，區塊之間留白充足。
- **顏色語意**：
  - `accent` 陶土橘＝品牌與本期主線；`sand` 沙色＝去年同期對照（虛線）與「中」級。
  - `pos` 綠＝正向、`neg` 紅＝負向；好壞永遠搭配 ▲▼ 與文字。
  - **小字不用 `accent`、`pos`、`sand` 原色**：連結與重點用 `accent-ink`，正向文字用 `pos-ink`，負向用 `neg-ink`，「中」級用 `sand-ink`（在 `sand-soft` 上）。原色對比不足（約 1.5–3.2:1），只當色點、資料條、圖形。
- **表格**：只有橫向細線（`line`），沒有垂直線與斑馬紋；表頭沒有底色填滿，只用 `ink-soft` 文字與底線；數字靠右、名稱靠左；分級用膠囊標籤。
- **圖表**：本期線 2.6px `chart-1` 實線＋10% 面積填色，資料點為卡片色填滿＋ 2px 描邊；去年同期 `chart-2` 2px 虛線（5 4）；只畫橫向格線（`line`）；環圈圖與資料條用 `chart-1`～`chart-5` 依序；圖例一定附數值或百分比。
- **陰影**：只有 `shadow-panel`（卡片）與 `shadow-float`（浮起的選單），都帶暖棕色、低透明度。

## 使用規則（Usage rules）

1. 文字色只用 `ink`、`ink-soft` 與各 `*-ink`；在 `accent-ink` 實心底上用 `card` 白字（約 5.4:1）。
2. 實心按鈕只用 `accent-ink` 底＋白字；不要做「`accent` 橘底＋白字」（約 2.8:1）。
3. 表單控制項（輸入框、下拉、外框按鈕）的外框用 `line-control`（≥ 3:1），不用 `line`。
4. 一個卡片只講一件事；卡片內最多一張圖或一張表。
5. 狀態標籤用「淡底＋深色字」：優／正向＝`pos-soft`＋`pos-ink`、中／留意＝`sand-soft`＋`sand-ink`、劣／重大＝`neg-soft`＋`neg-ink`，並附文字。
6. 圖表中的 `sand`、`chart-3`、`chart-5` 對比低，不可只靠顏色區分——用圖例、資料標籤或不同線型輔助。

## 何時使用這份設計系統

- 週報、月報、店長回顧、簡報截圖等「需要被好好閱讀」的儀表板。
- 同事或主管會長時間閱讀、對冷硬的報表風有壓力的場合。
- 需要高密度財務對帳時，改用報表風（例如 CASHBOX）；需要遠距離投影時，改用大螢幕看板。

## 交付原則

一次性分析用的 HTML 儀表板，一律照以下原則交付：

1. **單機、單一 HTML 檔，離線可用**：自己的樣式、腳本、圖示都內嵌在同一個檔案裡，雙擊就能在瀏覽器開啟；函式庫與字型的取得方式見第 3–5 點。不部署到任何雲端或網站，也不 push 到任何遠端儲存庫。
2. **資料只在瀏覽器裡處理**：使用者匯入的分類帳與調整數只在本機記憶體中運算，不上傳到任何伺服器、不留存。不使用 localStorage、sessionStorage、IndexedDB 或資料庫；關閉或重新整理頁面後資料即消失，每次使用重新匯入。
3. **資料絕不外送**：頁面不連任何外部網址。用內容安全政策（CSP）封鎖所有對外連線，放在 `<head>` 最前面：

```html
<meta http-equiv="Content-Security-Policy"
  content="default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; connect-src 'none'; worker-src blob:; form-action 'none'; base-uri 'none'">
```

   其中 `connect-src 'none'` 讓頁面無法用 fetch、XHR 或 sendBeacon 把資料送出去，`script-src` 不開放任何外部網址，這是防止資料外流的關鍵。
4. **函式庫一律內嵌**：xlsx、exceljs、chart.js 的原始碼（固定版本）直接放進同一個 HTML 檔，不從 CDN 載入，因此斷網也能用，也不會執行任何第三方即時下載的程式碼。
5. **字型不載入外部資源**：不使用 Google Fonts。字型依序為 Noto Sans TC（電腦裡有才會用）、PingFang TC、微軟正黑體，最後退回系統預設字型，斷網時版面不會壞。
6. 匯出（Excel、Word）由瀏覽器直接在本機產生並下載，不經過任何伺服器。

## 圖示與資產

- 不附標誌圖檔，也不使用圖示庫。品牌識別靠暖米色底與陶土橘主色；若需標誌，放在頁首標題左側、高度 32px，置於 `card` 底上。
- 圖示以單一中文字或色點表示；色點 8px 圓形。

## 元件

PageHero（標題頁首）、TabNav（膠囊頁籤）、Buttons（膠囊標籤與按鈕）、KpiCard（KPI 卡）、DataTable（柔和表格）。每個元件都有即時預覽與使用說明；預覽中的數字皆為示意資料。
