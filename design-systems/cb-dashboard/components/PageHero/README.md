頁面最上方的深色頁首，用於說明這份儀表板是什麼、分析期間與涵蓋範圍。

## 結構
- 底色 `ink`，疊兩層放射漸層（右上品牌藍、左上金色，透明度約 16–20%）。
- 下緣 6px 的藍–金–藍漸層條，是品牌簽名，不可省略。
- 由上而下：eyebrow 標籤（膠囊細框＋金色圓點）→ 襯線大標 `hero-title` → 副標 → 關鍵資訊列。
- 關鍵資訊列每項左側 2px 淡金線，標籤用 `hero-muted`，數值用襯線 19px。

## 規則
- 文字色只能用 `paper`、`hero-sub`、`hero-muted`、`gold-soft`（深底專用）。
- 一頁只放一個頁首；視窗窄時標題縮為 30px。
- 頁首內可放右上角「匯出報表」膠囊按鈕（半透明白底、淡金外框）。
