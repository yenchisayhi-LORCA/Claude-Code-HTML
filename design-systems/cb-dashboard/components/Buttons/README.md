膠囊按鈕、狀態標籤與燈號圓點。所有按鈕都是 `radius-pill`，文字 12–13px 粗體。

## 變體
- **外框按鈕（主要）**：`brand` 外框與文字、透明底；hover 填 `brand-soft`。用於展開／收合、查看明細、產生分析。展開狀態箭頭旋轉 180°。
- **幽靈按鈕**：`line` 外框、`ink-soft` 文字；hover 時轉 `brand`。用於重設、次要動作。
- **上傳按鈕**：`upload` 淡紫外框，僅用於檔案選擇；因對比偏低，文字必須粗體，新設計優先用外框按鈕。
- **狀態標籤**：正向（`pos-soft`／`pos`）、留意（`gold-soft`／`gold-ink`）、重大（`neg-soft`／`neg`）；一律短詞（2–4 字）。
- **燈號圓點**：8px，綠＝改善或持平、金＝下滑但仍為正、紅＝由正轉負或虧損擴大；必須附文字圖例。

## 規則
- 一個區塊內最多一組主要外框按鈕，避免並排超過三個。
- 不可只靠顏色表達狀態，標籤要有文字。
