## 版型
- **簡損表**：面板（`card`、`radius-lg`、`shadow-panel`）內分年度，新年度在上。表頭 12px、`ink-soft`、2px `ink` 底線；年度累計欄用 `paper-dim` 底並加粗；營業收入、營業淨利、EBITDA 為合計列（加粗、2px `ink` 上線）。

## 規則
- 單位「新台幣千元」寫在標題旁，四捨五入到整數，千分位逗號。
- 虧損以 `neg` 粗體顯示；增減率帶正負號與一位小數，營收類增加＝`pos`、減少＝`neg`（成本類相反）。
