結論字卡：用一張卡片講一個結論，由大標籤、大數字、短標題、一段說明組成。

## 結構
- 容器：`card` 底、`line` 邊框、`radius-md`、內距 22/20px；左側 4px 色條表示類型。
- 色條：`brand`＝關鍵發現／結構性關注、`gold`＝提示／季節性、`pos`＝正向、`neg`＝風險。
- 分類標籤：11.5px 粗體、`ink-soft`、字距 .1em。
- 大數字：`kpi-number`（襯線 26px 900），內容是百分比或門市名稱。
- 標題：`card-title`；說明：`body-card`，顏色 `ink-body`。

## 規則
- 一張卡片只講一件事；說明不超過三行。
- 排列使用自動格線（`minmax(300px,1fr)`），卡片之間 18px。
- 色條代表類型而非好壞；好壞用大數字旁的文字與顏色表達。
