# HD 損益儀表板

給連鎖 KTV 營運與財務團隊用的損益分析介面風格：像一本暖奶油色的月報，襯線標題、乾淨的數字表格，以橘、金、綠、磚紅四種顏色把「發生了什麼事」講清楚。版面與 CB 儀表板同一套結構，只是換成 HD 專屬的暖色調。

## 內容原則（Content fundamentals）

- **語言**：一律使用台灣繁體中文與台灣慣用詞（軟體、影片、資料）。數字用阿拉伯數字加千分位，單位寫在說明裡：「單位：新台幣千元」。
- **語氣**：像資深分析師寫給主管的短評——先講結論，再講數字，最後講原因。不用驚嘆號、不用表情符號當裝飾（燈號圓點例外）。
- **句型**：「本期為 X 元，較上期的 Y 元增加／減少 Z 元（±N%）」。本期數字開頭，再說明增減；百分比永遠帶正負號與一位小數。
- **名稱**：門市用顯示名稱，不用分類帳內部代號；HD 門市顯示名稱前方帶門市代碼數字。
- **科目稱呼**：用「科目小類」（人力成本、銷貨成本、水電瓦斯、辦公成本、租金成本、版權費用、折舊攤提、廣告費行銷、管顧費用、稅捐、其他）。
- **指標定義**：營業淨利＝營業收入－全部成本費用；EBITDA＝營業淨利＋折舊攤提。
- **小計定義**：HD KTV 小計是當月所有門市加總，不含 HD 總公司、店名含「餐」的門市、以及虛擬單位「139蘆洲1-2F」。

範例：
> 門市小計營業淨利下滑　−12.3%
> 2026年6月營業淨利為 4,820,000 元，較2026年5月的 5,497,000 元減少 677,000 元（−12.3%），建議搭配各門市與科目觀察確認具體成因。

## 視覺基礎（Visual foundations）

- **底色層次**：`paper`（頁面）→ `card`（卡片，更亮）→ `paper-dim`（次層：下拉、斑馬紋、說明區）。層次靠色差與 `line` 細邊框，不靠重陰影。
- **字型**：標題用 Noto Serif TC（粗、有份量），內文與數字表格用 Noto Sans TC，不載入外部字型，字型堆疊見「交付原則」第 5 點。
- **顏色語意**（最重要）：
  - `brand` 橘：導覽與主要互動（啟用頁籤、章節編號、按鈕外框）。
  - `gold` 金：提示與注意（觀察、說明邊條）。
  - `pos` 綠：改善、成本下降；`neg` 磚紅：虧損、成本上升。
  - **成本類數字的紅綠要反過來想**：成本增加用紅、減少用綠；營收／淨利類則增加用綠、減少用紅。
  - 「增減率前N」字卡用金色淡底（`gold-soft`），「增減率後N」字卡用中性灰米色（`down-group`）；刻意不使用紅綠，避免把成本下降誤讀成壞事。
  - 虧損（負值）金額一律以 `neg` 粗體顯示。
- **形狀**：所有按鈕、頁籤、狀態標籤都是膠囊（`radius-pill`）；卡片 14–16px 圓角；表格容器 14px。
- **頁首**：`ink` 深色底，右上橘色與左上金色的柔光（放射漸層），底部一條橘–金–橘的 6px 漸層條，作為品牌簽名。
- **陰影**：只有三種（panel、float、sticky），都是大模糊、負擴散、低透明度。
- **版面**：最大寬度 1180px、左右 28px；章節間距 64px；頁籤列黏在頂端（sticky）。
- **表格**：數字靠右、科目靠左；表頭 `ink` 底反白或 `ink-soft` 加 2px 底線；合計列加粗並以 2px `ink` 上線分隔；虧損數字紅字。
- **趨勢圖**：長條表示各年度金額、折線表示佔營收比，各年度依序取 `chart-1`～`chart-6`；折線一律繪在長條之上，偶數年度用虛線。

## 使用規則（Usage rules）

1. 文字色只用 `ink`、`ink-body`、`ink-soft`；在深色頁首上才用 `hero-muted`、`hero-sub`。
2. `brand`、`gold`、`pos` 不當小字文字色；要表達狀態時搭配色點、粗體或文字標籤（正向／留意／重大）。
3. 卡片左側 4px 色條表示類型：橘＝關鍵發現、金＝提示、綠＝正向、紅＝風險。
4. 一頁只有一個啟用頁籤（`brand` 底白字）；其餘為 `paper-dim` 底、`ink-soft` 字。
5. 數字顯示：千元表四捨五入到整數；需要精度時另存原值（data-raw），不要在畫面上放小數。

## 何時使用這份設計系統

- 用於 HD KTV 門市損益、成本、EBITDA 等分析儀表板與報表。
- 匯出 Excel、Word、HD RAW 時，依「匯出檔案規範」頁的格式。
- 一次性分析用的 HTML 儀表板，須遵守下方「交付原則」。

## 交付原則

一次性分析用的 HTML 儀表板，一律照以下原則交付：

1. **單機、單一 HTML 檔，離線可用**：自己的樣式、腳本、圖示都內嵌在同一個檔案裡，雙擊就能在瀏覽器開啟；函式庫與字型的取得方式見第 3–5 點。不部署到任何雲端或網站，也不 push 到任何遠端儲存庫。
2. **資料只在瀏覽器裡處理**：使用者匯入的分類帳與調整數只在本機記憶體中運算，不上傳到任何伺服器、不留存。不使用 localStorage、sessionStorage、IndexedDB 或資料庫；關閉或重新整理頁面後資料即消失，每次使用重新匯入。
3. **資料絕不外送**：頁面不連任何外部網址。用內容安全政策（CSP）封鎖所有對外連線，放在 `<head>` 最前面：

```html
<meta http-equiv="Content-Security-Policy"
  content="default-src 'none'; script-src 'unsafe-inline'; style-src 'unsafe-inline'; img-src data: blob:; font-src data:; connect-src 'none'; worker-src blob:; form-action 'none'; base-uri 'none'">
```

   其中 `connect-src 'none'` 讓頁面無法用 fetch、XHR 或 sendBeacon 把資料送出去，`script-src` 不開放任何外部網址，這是防止資料外流的關鍵。
4. **函式庫一律內嵌**：xlsx、exceljs、chart.js 的原始碼（固定版本）直接放進同一個 HTML 檔，不從 CDN 載入，因此斷網也能用，也不會執行任何第三方即時下載的程式碼。
5. **字型不載入外部資源**：不使用 Google Fonts。字型依序為 Noto Sans／Serif TC（電腦裡有才會用）、PingFang TC、微軟正黑體，最後退回系統預設字型，斷網時版面不會壞。
6. 匯出（Excel、Word）由瀏覽器直接在本機產生並下載，不經過任何伺服器。

## 圖示與資產

不使用圖示庫。科目圖示是單一中文字（人、貨、電、水、修）放在 38px 圓角方塊裡，底色為 `brand-soft` 或 `gold-soft`；章節編號是 30px 橘色細框圓形。沒有標誌檔案，品牌以文字標題呈現。

## 元件

PageHero（頁首）、TabNav（頁籤列）、Buttons（膠囊按鈕）、ConclusionCard（結論字卡）、DataTable（損益表格）、AnomalyCard（異常觀察卡）。每個元件都有即時預覽與使用說明。
