# 📝 待辦清單 To-Do List

單一 HTML 檔案的待辦清單，配色鮮明活潑（藍／薄荷綠／黃／珊瑚橘／粉紅），每一行事項都有自己的底色，資料只存在瀏覽器 `localStorage`，**不需要登入、不需要伺服器、不會跨裝置同步**——純粹在手機的 Chrome 上打開就能用。

## 如何使用

直接用手機或電腦的 Chrome 開啟 `index.html` 即可（可以雙擊打開，也可以放到 GitHub Pages / 隨便一個靜態空間再用手機瀏覽器開）。想要更像 App 一點，可以在 Chrome 選單選「加到主畫面」，之後就會有一個獨立的圖示可以點。

## 功能

- **新增事項**：每一筆都有「日期」與「事項內容」兩個欄位。
- **打勾完成**：每個事項前面有圓形勾選框，點下去打勾、文字會加上刪除線；已完成的事項預設仍留在清單裡（半透明＋刪除線），不會被藏起來。
- **一行一個事項**：不依日期分組，就是單純的清單，由日期新到舊（早到晚）排序；每一行都會標示自己的日期（今天／明天／幾月幾日 星期幾）。
- **每行不同底色**：新增事項時會依序循環套用藍／薄荷綠／黃／珊瑚橘／粉紅五種鮮明底色，讓整個畫面色彩豐富、容易一眼分辨不同事項。
- **隱藏／顯示已完成**：上方「隱藏已完成」按鈕可以切換是否顯示已勾選的事項。
- **編輯／刪除**：每個事項都有 ✏️ 編輯（可改日期與內容）、🗑 刪除按鈕；刪除後有 5 秒「復原」的提示，避免手滑刪錯。
- **完成進度**：標題卡片顯示「X／Y 已完成」以及一條彩色進度條。
- **備份與還原**：因為資料不會同步、也不會自動備份到雲端，下方提供「⬇️ 匯出備份／⬆️ 匯入備份」，可以匯出成一個 JSON 檔案存起來（例如存到雲端相簿、Line 給自己等），日後在同一支手機或換手機時匯入即可還原所有事項。
- **清除已完成**：一鍵清掉所有已勾選完成的事項，保持清單乾淨。

## 資料儲存與限制

- 所有資料存在瀏覽器的 `localStorage`，只存在「目前這個瀏覽器」。清除瀏覽器資料、換手機、換瀏覽器（例如從 Chrome 換到 Safari）都會遺失紀錄，請養成定期「匯出備份」的習慣。
- 這是刻意的設計：因為需求是「不用同步、只在自己手機上用」，所以沒有加登入或雲端同步功能，讓工具保持單一檔案、開箱即用。

## 之後可以再補充的功能構想

以下是還沒實作、但之後如果想擴充可以考慮的方向：

- **重複事項**：設定每天／每週自動出現的事項（例如每天倒垃圾），完成後自動產生下一次。
- **分類標籤**：幫事項加上「學習／家事／運動」之類的分類圖示，方便篩選。
- **拖曳排序**：手動調整清單順序，不一定照日期排。
- **提醒通知**：用瀏覽器的 Notification API 在指定時間提醒尚未完成的事項（需要使用者允許通知權限，且手機瀏覽器背景執行有限制）。
- **統計圖表**：一週／一個月的完成率折線圖，方便回顧。
- **深色模式**：夜間使用時可切換較暗的配色。
- **語音輸入**：用手機瀏覽器的語音輸入快速新增事項（免打字）。

如果之後想要「多裝置同步」，可以參考同一個 repo 底下 `kids-reward-tracker/` 專案的 Firebase 雲端同步作法，但那會讓工具從「單一檔案」變成需要架設或設定 Firebase 專案，跟目前「越簡單越好」的需求方向不同，所以沒有預設加入。
