# 🌟 獎勵待辦清單 Reward To-Do List

單一 HTML 檔案的待辦清單，視覺風格參考兒童獎勵行事曆（藍／黃／薄荷綠配色＋文具貼紙插畫），資料只存在瀏覽器 `localStorage`，**不需要登入、不需要伺服器、不會跨裝置同步**——純粹在手機的 Chrome 上打開就能用。

## 如何使用

直接用手機或電腦的 Chrome 開啟 `index.html` 即可（可以雙擊打開，也可以放到 GitHub Pages / 隨便一個靜態空間再用手機瀏覽器開）。想要更像 App 一點，可以在 Chrome 選單選「加到主畫面」，之後就會有一個獨立的圖示可以點。

## 功能

- **新增任務**：可設定日期、分類（📖 學習／🧹 家事／🏃 運動／🎨 玩樂／🦷 生活習慣／🍎 飲食／⭐ 其他）、事項內容，以及是否每天／每週重複。
- **打勾完成**：每個任務前面有圓形勾選框，點下去會有星星彩帶動畫，並跳出「+1 ⭐ 太棒了！」的提示。
- **獎勵機制**：
  - ⭐ 累積星星：每完成一個任務就 +1，就算之後不小心取消勾選也不會扣掉，星星只會越集越多。
  - 🔥 連續天數：只要當天有完成至少一項任務，就算連續一天，統計目前連續天數的 streak。
  - ✅ 今日進度條：即時顯示今天任務的完成比例。
  - 🎉 當天任務全部完成時，會跳出全螢幕慶祝畫面。
- **依日期分組顯示**，並可用上方分頁篩選「今天／本週／已完成／全部」。
- **重複任務**：設定每天或每週重複的任務，打勾完成後會自動產生下一次的任務。
- **編輯／刪除**：每個任務都有 ✏️ 編輯、🗑 刪除按鈕；刪除後有 5 秒「復原」的提示，避免手滑刪錯。
- **備份與還原**：因為資料不會同步、也不會自動備份到雲端，右下角提供「⬇️ 匯出備份／⬆️ 匯入備份」，可以匯出成一個 JSON 檔案存起來（例如存到雲端相簿、Line 給自己等），日後在同一支手機或換手機時匯入即可還原所有任務、星星與連續天數紀錄。
- **清除已完成**：一鍵清掉所有已勾選完成的任務，保持清單乾淨。

## 資料儲存與限制

- 所有資料存在瀏覽器的 `localStorage`，只存在「目前這個瀏覽器」。清除瀏覽器資料、換手機、換瀏覽器（例如從 Chrome 換到 Safari）都會遺失紀錄，請養成定期「匯出備份」的習慣。
- 這是刻意的設計：因為需求是「不用同步、只在自己手機上用」，所以沒有加登入或雲端同步功能，讓工具保持單一檔案、開箱即用。

## 之後可以再補充的功能構想

以下是還沒實作、但之後如果想擴充可以考慮的方向：

- **音效**：完成任務時播放一小段音效（需要額外音檔或用 Web Audio 產生音效）。
- **獎勵兌換商店**：星星累積到一定數量可以「兌換」自訂的小獎勵（例如：看電視 30 分鐘、買一個小禮物），並扣除對應星星數。
- **多人／多小孩模式**：如果不只一個人使用，可以加上切換使用者的功能，各自累積自己的星星與清單。
- **提醒通知**：用瀏覽器的 Notification API 在指定時間提醒尚未完成的任務（需要使用者允許通知權限，且手機瀏覽器背景執行有限制）。
- **統計圖表**：一週／一個月的完成率折線圖或月曆熱力圖，方便回顧養成習慣的狀況。
- **拖曳排序**：手動調整同一天任務的顯示順序。
- **深色模式**：夜間使用時可切換較暗的配色。

如果之後想要「多裝置同步」或「家長／小孩分開登入管理」，可以參考同一個 repo 底下 `kids-reward-tracker/` 專案的 Firebase 雲端同步作法，但那會讓工具從「單一檔案」變成需要架設或設定 Firebase 專案，跟目前「越簡單越好」的需求方向不同，所以沒有預設加入。
