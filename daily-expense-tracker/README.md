# 🧾 日常記帳 Daily Expense Tracker

單一 HTML 檔案的日常記帳工具，可以建立多本不同用途的「帳本」（例如日常、旅遊、餐飲），每本帳本分別記錄花費與備註。資料只存在瀏覽器 `localStorage`，**不需要登入、不需要伺服器、不會跨裝置同步**。

## 如何使用

直接用手機或電腦的瀏覽器開啟 `index.html` 即可（可以雙擊打開，也可以放到 GitHub Pages / 隨便一個靜態空間再用手機瀏覽器開）。想要更像 App 一點，可以在瀏覽器選單選「加到主畫面」，之後就會有一個獨立的圖示可以點。

## 功能

- **多本帳本**：首頁可以新增多本帳本（例如日常、旅遊），每本帳本自己的圖示、名稱與總金額都會列在清單上。
- **帳本管理**：點左上角管理圖示可以切換「管理模式」，這時每本帳本前面會出現 ✕ 刪除按鈕（刪除後有 5 秒「復原」提示，避免手滑刪錯）；點右上角 ✏️ 可以重新命名或換圖示。
- **快速新增紀錄**：進入帳本後，最上面有一個輸入框，直接打「金額」或「金額 備註」（例如 `250 午餐`）按 Enter 就能新增一筆紀錄，日期與時間自動帶入當下時間。
- **表單新增／編輯**：也可以點右下角圓形 ＋ 按鈕，用「金額」「備註」兩個欄位分開輸入；點清單裡任一筆紀錄可以編輯，儲存後時間會自動更新成編輯當下的時間。
- **總計與統計**：帳本頁最上方會顯示 `Σ 目前總金額`，點一下會提示這本帳的筆數與平均每筆金額。
- **清空／匯出**：底部工具列可以清空目前這本帳的所有紀錄（可復原），或是把這本帳、或全部帳本匯出成 CSV（支援裝置分享或直接下載）。
- **手繪塗鴉風配色**：介面延續同一個 repo 裡「旅遊記帳系統」的視覺語言（Baloo 2 圓體字型、奶油底＋彩色色塊背景、卡片式清單），風格活潑好認。
- **加入主畫面**：有設定 `apple-touch-icon`、`manifest.json` 等，加入主畫面後會用自訂圖示、以全螢幕 App 的方式開啟。

## 資料儲存與限制

- 所有資料存在瀏覽器的 `localStorage`，只存在「目前這個瀏覽器」。清除瀏覽器資料、換手機、換瀏覽器都會遺失紀錄，請記得用「匯出」功能定期備份成 CSV。
- 這是刻意的設計：保持單一檔案、開箱即用，沒有加登入或雲端同步功能。

## 專案結構

```
index.html   所有畫面結構、樣式與邏輯都在這一個檔案裡
manifest.json PWA 設定
icons/        App 圖示（加到主畫面用）
```
