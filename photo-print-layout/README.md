# 🖼️ 照片沖印排版

純前端（HTML/CSS/JavaScript，無框架、無建置流程）的照片排版工具：先建立一份「底稿樣板」（你自己的背景設計圖 + 1～3 個照片框位置），之後就能重複套用照片、匯出成適合送洗沖印的 4×6 或 5×7 吋圖檔。跟拍立得、魔圖這類拼貼 App 的差異，是版型完全由你自己上傳、自己框位置，不受限於內建的固定樣式。

這個 repo 裡還有其他完全獨立的小工具（例如根目錄的旅遊記帳系統、[小孩獎勵紀錄本](../kids-reward-tracker/README.md)），彼此無關，只是共用同一個 repo。

## 功能

- **自訂底稿樣板**：上傳自己的底稿圖片（例如卡片邊框、拼貼設計），在畫面上直接拖曳／縮放框出 1～3 個照片要放的位置，存成可重複使用的樣板。同一份樣板之後每次套用都是同樣的框位置。
- **樣板管理**：所有樣板存在瀏覽器 localStorage，列表可預覽縮圖（含框位置）、編輯、刪除。
- **套用樣板匯出**：選一份樣板，依框數上傳 1～3 張照片（不必每個框都放滿），每張照片可拖曳調整位置、用滑桿縮放，即時預覽最終合成畫面。
- **沖印品質輸出**：匯出的 PNG 圖檔固定用 300 DPI 對應解析度（4×6 吋 = 1200×1800 px，5×7 吋 = 1500×2100 px），適合直接送去沖印店印出實體照片。

## 版型設計原則（v1 的簡化限制）

- 照片框一律是矩形、不能旋轉；如果需要斜貼效果，之後可以再擴充。
- 合成順序固定是「底稿背景先畫、照片疊在框的位置上面」，所以底稿裡照片要放的區域只要留白（不需要挖透明洞）即可；如果你的底稿設計是「裝飾框疊在照片上面」（例如相框邊角蓋住照片邊緣），目前版本還不支援，需要另外討論怎麼調整合成順序。
- 每份樣板的沖印尺寸（4×6 或 5×7）建立時就要選好；更換尺寸時底稿圖會依新的長寬比重新「鋪滿裁切」，框的相對位置不會變，但畫面比例會跟著新尺寸調整。

## 如何執行

這是純前端專案，但因為使用了 ES modules，瀏覽器對 `file://` 協定會有安全限制，**需要透過本機伺服器開啟**，不能直接雙擊 `index.html`。任選一種方式：

```bash
# 方法一：Python
python3 -m http.server 8080

# 方法二：Node.js
npx serve .
```

然後用瀏覽器開啟對應的網址（例如 `http://localhost:8080/photo-print-layout/`）。

## 部署

因為是純靜態網頁，可直接部署到 GitHub Pages、Netlify、Vercel 等靜態代管服務，不需要任何後端設定。

## 資料儲存與限制

- 樣板（底稿圖 + 框位置）存在瀏覽器的 `localStorage`，**只存在於目前這個瀏覽器/裝置**，換瀏覽器或清除瀏覽器資料會遺失樣板。
- 你在「套用樣板」畫面上傳的照片**不會被存起來**，只存在當下這次瀏覽器分頁的記憶體裡；離開頁面或重新整理後要重新上傳。這是刻意的設計，避免大量照片把 localStorage 的容量（通常只有 5MB 左右）塞滿。
- localStorage 有容量上限，每份樣板的底稿圖都是 300 DPI 的沖印解析度（通常幾百 KB），建議樣板數量不要無限增加；如果儲存失敗（畫面上會跳出提示），刪除不需要的舊樣板即可釋放空間。

## 專案結構

```
index.html          三個畫面的結構：樣板列表、樣板編輯器、套用樣板匯出
css/style.css        樣式
js/
  app.js             畫面切換（gallery/editor/export）與樣板列表渲染
  storage.js         樣板的 localStorage 存取（CRUD）＋沖印尺寸的像素規格對照表
  image.js           圖片載入、底稿的「鋪滿裁切」轉換
  compositor.js      畫布合成：把底稿背景 + 各框照片畫在一起，預覽跟匯出共用同一套邏輯
  editor.js          樣板編輯器：拖曳／縮放照片框、上傳底稿、儲存樣板
  exporter.js        套用樣板：每格照片的上傳、拖曳、縮放，以及最終匯出 PNG
```
