# 📝 筆記・童趣風備忘錄（Scriptable）

在 iPhone 上用 [Scriptable](https://scriptable.app/) 打開的備忘錄，配色照設計系統「童趣風」。首頁是兩欄卡片，每則筆記的標題、勾選清單、文字和照片縮圖都直接看得到。

## 功能

- **兩欄卡片預覽**：每張卡片顯示圖示、標題、分類、前 5 行內容和照片縮圖；清單全部打勾的卡片變成淡青色，右下角顯示進度（例如 3/4）。
- **自動存檔**：編輯筆記時，按完成、按返回、點面板外面，或直接按 Scriptable 的 Close，都會存檔（跟 iPhone 備忘錄一樣）；沒改任何東西就不會更動修改時間。
- **勾選清單鍵**：寫筆記時，工具列左邊的鍵會把游標所在的那一行變成勾選項目，再按一次變回文字。勾選項目按換行，下一行也是勾選項目；空的勾選項目按換行會變回文字，跟 iPhone 備忘錄一樣。
- **圖示**：點標題左邊的圖示可以換，跟[日常記帳](../daily-expense-tracker/README.md)同一套 13 隻小動物，加上 29 個貼紙圖示（日常記帳的線條圖示＋氣球）。貼紙跟[童趣風月曆](../iphone-calendar-widget/README.md)的生日貼紙一樣有塗色和不規則底色，每個圖示的顏色固定（星星黃色、愛心紅色），寫在 `stickers.js`。
- **分類**：可以新增、改名、選顏色（黃、橘、綠、藍、粉、青、紫、桃紅 8 色）、刪除；新分類會先挑還沒用過的顏色，儘量不重複。刪掉的分類，裡面的筆記會變成「不分類」。首頁可以按分類、未完成、有照片篩選，也可以搜尋。
- **照片**：工具列右邊的鍵可以從相簿選或直接拍照。照片存一張長邊 1000 像素的大圖和一張縮圖，點照片可以放大看。
- **釘選**：打開筆記（或在編輯畫面）按圖釘鍵，釘選的筆記在 App 和小工具都排在最前面，卡片右上角有紅色圖釘；再按一次取消。
- **刪除筆記**：點卡片打開，按右上角的垃圾桶再按一次確認；或在編輯畫面最下面按「刪除這則筆記」。
- **主畫面小工具**：小、中、大三種尺寸，顯示最近改過的筆記，點卡片會直接打開那則筆記的編輯畫面。左上角是跟[童趣風月曆](../iphone-calendar-widget/README.md)一樣的「彥」圖示（跟月曆共用「圖示文字」設定），卡片用分類的顏色（同一個小工具裡的卡片不會同色，重複時自動換成沒用過的顏色），四周有彩色色塊。
- **只顯示某個分類**：長按小工具 →「編輯小工具」→ Parameter 填分類名稱（例如「採買」），那個小工具就只顯示這個分類，標題也變成分類名稱（主畫面的卡片不顯示分類標籤、修改日期和清單進度）；填「未完成」只顯示還沒打勾完的清單；清空就顯示全部。點卡片以外的地方，會打開筆記並篩選成那個分類。
- **跟月曆疊在一起**：兩個都選大尺寸，在主畫面編輯模式把一個拖到另一個上面，就會變成可以上下滑的堆疊。

## 安裝

1. 在 Scriptable 按右上角 ＋ 新增腳本，把 `kids-notes.js` 的內容整段貼上，命名為例如「筆記」。
2. 網路開著，按 ▶︎ 執行一次。第一次會下載小動物圖示，之後打開就是筆記畫面。
3. 想放主畫面小工具：長按主畫面 →「編輯」→「加入小工具」→ Scriptable → 選尺寸 → 長按小工具 →「編輯小工具」→ Script 選「筆記」。
4. 想像 App 一樣從主畫面一鍵打開：在「捷徑」App 新增捷徑 → 加入 Scriptable 的「Run Script」→ 選「筆記」→ 加入主畫面。

## 資料存在哪裡

- 筆記、分類存在 iCloud 雲碟的 `Scriptable/kids-notes/notes.json`，照片在 `photos/`，小動物圖示在 `icons/`。沒開 iCloud 雲碟時存在本機。
- 每天會留一份 `notes-backup.json` 備份。`notes.json` 讀不到時會改讀備份。
- 同一個 Apple 帳號的裝置共用同一份資料。兩台裝置同時打開編輯，以最後存檔的那台為準。
- 沒有任何筆記在用、而且放超過 7 天的照片，會在關掉筆記畫面時刪掉。

## 檔案

- `kids-notes.js`：貼到 Scriptable 的完整腳本（由 `build.py` 產生，不要直接改）。
- `main.js`：Scriptable 這一側的程式（存檔、照片、小工具）。
- `page.html`：筆記畫面。
- `stickers.js`：圖示貼紙的塗色和底色。
- `build.py`：把 `page.html`、日常記帳的線條圖示和 `stickers.js` 塞進 `main.js`，產生 `kids-notes.js`。改完 `main.js` 或 `page.html` 後執行 `python3 scriptable-notes/build.py`。
