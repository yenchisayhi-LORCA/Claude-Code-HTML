# 🗓️ 待辦事項・童趣風行事曆小工具（Scriptable）

用 [Scriptable](https://scriptable.app/) 讀 iPhone 內建「行事曆」的活動和「提醒事項」，做成童趣風的主畫面小工具，取代內建的行事曆小工具。只顯示自己建立的行事曆（可以編輯的）和通訊錄朋友的生日；內建的節日（例如「重陽節」）和訂閱的行事曆不顯示。

## 長相

- **左上角**：跟[童趣風月曆](../iphone-calendar-widget/README.md)同一個字圖示（例如「彥」，跟著月曆設定的圖示文字），旁邊是今天的日期（深藍色）和農曆（例如「九月初二」），跟圖示裡的字對齊在同一條底線。農曆用內建的 1900–2100 對照表（小工具裡不能用系統的農曆格式）。
- **依日期分組**：「今天」「明天」「10/15 星期四」，日期旁邊加農曆；今天沒行程時顯示「今天沒有其他行程，好好休息」。
- **卡片**：
  - 提醒事項是空心圓圈，第二行是到期時間；過期沒完成的放在「今天」，圓圈和文字變紅色「已過期」。
  - 行事曆活動是彩色小圓點，右邊上面是開始、下面是結束時間；全天活動寫「整天」。
  - 沒有日期的提醒事項放在最後的「待辦」。
- **底圖**：大尺寸的行程整組往下一點，第一張卡片在右上角照片下面；卡片和日期左右各縮 12 點，底圖左邊的綠色、右邊的橘色左右對稱露出來（離卡片約 4 點，壓不到），左下的粉紅改小（最後一張卡片壓不到），下面的藍色放大一點（底圖由筆記腳本畫，改版後要先在筆記按 ▶︎，再在這裡執行一次）。
- **右上角的照片**：在 Scriptable 裡執行這個腳本，選單選「換右上角的照片」，可以把右上角的黃色色塊換成一張相簿裡的照片（外框跟色塊同一個形狀），也可以拿掉改回黃色色塊。照片存在 iCloud 的 `kids-agenda/`，兩台裝置共用；另一台要在 Scriptable 裡執行一次這個腳本，小工具才會換（跟筆記小工具的照片分開設定）。
- **顏色**：卡片底色從筆記分類的顏色裡挑黃、橘、綠、藍、紫 5 色（不用粉紅、青色、桃紅，免得跟底圖左下、右下的色塊混在一起），依行程隨機挑（同一個行程每次都同色），同一個小工具裡的卡片都不同色（超過 5 張才會重複）。
- **放得下多少就顯示多少**，不顯示「還有幾筆」。
- 中、小尺寸不分日期，直接列出接下來最近的幾筆，時間前面寫「明天」「10/15 週四」。
- 點小工具打開行事曆；點提醒事項的卡片打開提醒事項。

## 安裝

1. 先裝好[童趣風月曆](../iphone-calendar-widget/README.md)和[筆記](../scriptable-notes/README.md)腳本，並在這台裝置各按過 ▶︎（左上的字圖示是月曆腳本畫的，彩色底圖是筆記腳本畫的，用的是沒有手繪菱形的底圖；沒有月曆圖示時改用筆記的第一個字圖示，都沒有就只顯示米白底和日期）。
2. 在 Scriptable 新增腳本，貼上 `agenda.js`，命名為例如「待辦事項」。
3. 按 ▶︎ 執行一次，第一次會詢問「允許取用行事曆」和「允許取用提醒事項」，都按允許；之後可以預覽大、中、小尺寸。
4. 主畫面加 Scriptable 小工具 → 長按 →「編輯小工具」→ Script 選「待辦事項」。也可以跟月曆、筆記疊成堆疊（同尺寸）。

只能讀取和顯示；新增或修改行程請用內建的行事曆、提醒事項 App。小工具每 15 分鐘左右和每天 0 點更新（實際時間由 iOS 決定，常常會晚一點；改了行程或提醒事項後，小工具不會馬上變）。
