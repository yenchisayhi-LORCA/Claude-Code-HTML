# 🗓️ 待辦事項・童趣風行事曆小工具（Scriptable）

用 [Scriptable](https://scriptable.app/) 讀 iPhone 內建「行事曆」的活動和「提醒事項」，做成童趣風的主畫面小工具，取代內建的行事曆小工具。

## 長相

- **左上角**：跟[筆記](../scriptable-notes/README.md)小工具同一組字圖示（例如「林小琪」），旁邊是今天的日期（紅色）和農曆（例如「九月初二」）。
- **依日期分組**：「今天」「明天」「10/15 星期四」，日期旁邊加農曆；今天沒行程時顯示「今天沒有其他行程，好好休息」。
- **卡片**：
  - 提醒事項是空心圓圈，第二行是到期時間；過期沒完成的放在「今天」，圓圈和文字變紅色「已過期」。
  - 行事曆活動是彩色小圓點，右邊上面是開始、下面是結束時間；全天活動寫「整天」。
  - 沒有日期的提醒事項放在最後的「待辦」。
- **顏色**：卡片底色跟筆記分類同一組 8 色，依行程隨機挑（同一個行程每次都同色），相鄰兩張不會同色。
- **放得下多少就顯示多少**，不顯示「還有幾筆」。
- 中、小尺寸不分日期，直接列出接下來最近的幾筆，時間前面寫「明天」「10/15 週四」。
- 點小工具打開行事曆；點提醒事項的卡片打開提醒事項。

## 安裝

1. 先裝好[筆記](../scriptable-notes/README.md)腳本，並在這台裝置按過 ▶︎（字圖示和彩色底圖是筆記腳本畫的，這個小工具直接沿用；沒有的話就只顯示米白底和日期）。
2. 在 Scriptable 新增腳本，貼上 `agenda.js`，命名為例如「待辦事項」。
3. 按 ▶︎ 執行一次，第一次會詢問「允許取用行事曆」和「允許取用提醒事項」，都按允許；之後可以預覽大、中、小尺寸。
4. 主畫面加 Scriptable 小工具 → 長按 →「編輯小工具」→ Script 選「待辦事項」。也可以跟月曆、筆記疊成堆疊（同尺寸）。

只能讀取和顯示；新增或修改行程請用內建的行事曆、提醒事項 App。小工具每 30 分鐘左右和每天 0 點更新（實際時間由 iOS 決定）。
