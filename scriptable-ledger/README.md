# 💰 記帳・童趣風快速記帳（Scriptable）

在 iPhone 上用 [Scriptable](https://scriptable.app/) 打開的快速記帳，配色照設計系統「童趣風」。跟網頁版[日常記帳](../daily-expense-tracker/README.md)一樣單純：記一筆、看總額、匯出到自己的 Excel 帳冊，記錄只放在這台 iPhone 上。

## 功能

- **多本帳本**：首頁列出每本帳本的圖示、名稱、筆數和總額。按「＋新帳本」新增；按右上角 ✎ 進入管理，點帳本可以改名字、圖示、顏色，按 ✕ 再按一次刪除整本（5 秒內可以復原）。
- **記一筆**：大數字鍵盤輸入金額（可以有小數點），點分類，備註可以不填。日期時間自動帶入，也可以改。點帳本裡的任一筆可以修改或刪除。
- **分類**：預設餐飲、交通、購物、日用、娛樂、醫療、孩子 7 個，所有帳本共用。可以新增、改名、刪除，顏色和圖示跟[筆記](../scriptable-notes/README.md)同一套（8 色；13 隻小動物和 31 個貼紙圖示）。刪掉的分類，用到它的記錄顯示「未分類」。
- **匯出到 Excel**：帳本裡按「匯出 CSV」，用分享選單存到「檔案」或用 LINE、Email 傳出去（開頭有 BOM，Excel 打開中文不會亂碼）；按「複製給 Excel」，直接在 Excel 貼上會自動分欄。欄位是日期、時間、帳本、分類、金額、備註，舊的在上面。
- **清空**：貼進帳冊之後按「清空」再按一次「確定清空」，5 秒內可以復原。
- **主畫面小工具**：小、中尺寸。自動顯示最近記帳的那本帳本：今天花了多少、全部多少；中尺寸再列最近 3 筆。點「＋記一筆」直接打開記帳畫面，點其他地方打開那本帳本。想固定顯示某一本，長按小工具 →「編輯小工具」→ Parameter 填帳本名稱。左上角的「彥」和彩色底圖沿用[童趣風月曆](../iphone-calendar-widget/README.md)和筆記在這台畫好的圖（沒裝的話只顯示米白底）。

## 安裝

1. 在 Scriptable 按右上角 ＋ 新增腳本，把 `kids-ledger.js` 的內容整段貼上，命名為例如「記帳」。
2. 網路開著，按 ▶︎ 執行一次。第一次會下載小動物圖示、畫好小工具用的貼紙圖。
3. 想放主畫面小工具：長按主畫面 →「編輯」→「加入小工具」→ Scriptable → 選小或中尺寸 → 長按小工具 →「編輯小工具」→ Script 選「記帳」。

## 資料存在哪裡

- 只存在這台 iPhone：Scriptable 本機資料夾的 `kids-ledger/ledger.json`，不上 iCloud，兩台手機各記各的。每次存檔會把上一版留在 `ledger-backup.json`。
- 刪掉 Scriptable 或換手機，記錄就會不見，所以匯出就是你的備份：記得定期匯出貼到 Excel 帳冊，再清空。

## 檔案

- `kids-ledger.js`：貼到 Scriptable 的完整腳本（由 `build.py` 產生，不要直接改）。
- `main.js`：Scriptable 這一側的程式（存檔、匯出、小工具）。
- `page.html`：記帳畫面。
- `build.py`：把 `page.html`、日常記帳的線條圖示和筆記的貼紙樣式（`scriptable-notes/stickers.js`）塞進 `main.js`，產生 `kids-ledger.js`。改完後執行 `python3 scriptable-ledger/build.py`。
